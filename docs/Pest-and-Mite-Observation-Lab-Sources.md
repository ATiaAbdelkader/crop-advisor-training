# Pest and Mite Observation Evidence Lab: Design Sources

| Source | Design implication |
|---|---|
| [FAO, *How to practice Integrated Pest Management*](https://www.fao.org/agriculture/crops/thematic-sitemap/theme/spi/scpi-home/managing-ecosystems/integrated-pest-management/ipm-how/en/) | Observation should include crop condition, pest presence, natural enemies, and wider agroecosystem context. A local threshold is only one decision input and must not be assumed by this course. |
| [Oklahoma State University Extension, *IPM—Scouting and Monitoring for Pests in Commercial Greenhouses*](https://extension.okstate.edu/fact-sheets/ipm-scouting-and-monitoring-for-pests-in-commercial-greenhouses) | Repeatable routes, mapped observation units, life-stage-aware identification, visible records, and monitoring changes over time strengthen field scouting. |

The Module 31 lab will reinforce observation, identification limits, evidence comparison, and referral. It will not supply pest thresholds, pesticide products, rates, mixing, timing, or application directions.
