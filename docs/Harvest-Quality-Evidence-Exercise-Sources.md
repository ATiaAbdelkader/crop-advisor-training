# Harvest Quality Evidence Exercise: Design Sources

| Source | Design implication |
|---|---|
| [FAO, *Small-Scale Postharvest Handling Practices*](https://www.fao.org/4/ae075e/ae075e02.htm) | Harvest and postharvest systems have many linked handling steps; quality review should observe damage, sorting, temperature context, handling, and records rather than assume a single cause. |
| [Tennessee Vegetable Extension, *Traceability*](https://vegetables.tennessee.edu/food-safety/traceability/) | Traceability connects the field and downstream buyer records; learners should create a short handover record and refer local food-safety requirements to authorised guidance. |

The Module 28 exercise will support maturity observation, handling-risk recognition, traceability notes, and escalation. It will not specify harvest indices, food-safety rules, storage conditions, treatments, or commercial requirements.
