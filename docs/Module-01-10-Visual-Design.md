# Module 01–10 Instructional Visual Design

The first ten modules now use a consistent, text-free editorial agronomy visual directly below the active-lesson summary. Each image is a learning cue rather than a decorative banner: it establishes the field setting, directs attention to the decision context, and reinforces the practical work addressed in the lesson.

| Module range | Visual emphasis | Learning purpose |
|---|---|---|
| 01–03 | Observation, soil profile, and field scouting | Reinforces the distinction between visible evidence, field pattern, and diagnosis. |
| 04–06 | Farm system planning, cost decisions, and crop/variety comparison | Connects paper-based decisions to the farm, market, and production context. |
| 07–10 | Interacting yield factors, climate, topography, and soil properties | Makes environmental evidence visible before learners choose an intervention. |

Every visual is supplied with a specific alternative description and a concise caption. The alternative description identifies the people, field condition, and evidence visible in the image. The caption links that evidence to the relevant learning principle, so a learner does not need to infer instructional significance from an image alone.

The image treatment uses a consistent 16:7 crop within a bordered learning card. It is presented before lesson outcomes and section content, allowing the visual to orient the learner without interrupting the structured lesson sequence, completion gate, assessment route, or applied field brief.
