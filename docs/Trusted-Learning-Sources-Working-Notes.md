# Trusted Learning Sources: Working Notes

## FAO Farmer Field School platform

The [FAO Global Farmer Field School overview](https://www.fao.org/farmer-field-schools/overview/en/) describes a people-centred, participatory learning approach. It identifies practical field exercises, direct observation, discussion, decision-making, local-context problem analysis, and the testing and integration of local knowledge with scientific insights as core features. It also describes field-based experimentation, critical analysis, and improved decision-making as intended outcomes.

**Design implication:** The course’s signature layer should guide learners through an explicit field question, observation plan, local-context interpretation, bounded decision, and recheck/referral condition. It should support testing rather than presenting a universal prescription and should allow learners to compare local evidence with the module’s scientific concept.

**Source:** Food and Agriculture Organization of the United Nations, *Overview: Global Farmer Field School Platform*, accessed 26 August 2026.

## UNESCO-UNEVOC and related work-based learning sources

The [UNESCO-UNEVOC TVETipedia work-based learning entry](https://connect.unevoc.unesco.org/home/TVETipedia+Glossary/lang=en/show=term/term=work-based+learning) links work-based learning to practical instruction and participation in work activities under guidance. The [ILO work-based learning resource](https://www.ilo.org/publications/work-based-learning-technical-and-vocational-education-and-training) and [Cedefop definition](https://www.cedefop.europa.eu/en/publications/2300) provide complementary institutional foundations for learning in real work environments and structured work-relevant practice.

**Design implication:** Each learning routine should make the work context explicit, require an observable action or evidence record, and use bounded instructor/supervisor feedback rather than treating a knowledge check as sufficient evidence of field competence.

## FAO agroecosystem analysis

The [FAO Knowledge Repository resource on Farmer Field School agroecosystem analysis](https://openknowledge.fao.org/handle/20.500.14283/cb6742en) identifies Agro Ecosystem Analysis as a core Farmer Field School practice involving crop or commodity observation, data collection, analysis, and decision-making. The repository page did not render full body text in the browser, so the implementation will use only this high-level, corroborated sequence and will avoid importing technical prescriptions.

**Design implication:** Build a repeatable sequence of **question → observe → record → analyse → decide → recheck/refer**, with context-specific prompts rather than universal action advice.
