# Crop-Walk Evidence Lab: Design Sources

The Module 3 enhancement uses a broad-to-focused crop-walk workflow: define the field question, follow a repeatable route, compare representative and unusual areas, record observations before interpretation, state uncertainty, and choose a safe next check or referral.

| Source | Design implication used in the lab |
|---|---|
| [FAO, *Understanding the Farmer Field School agro-ecosystem analysis (AESA) process*](https://openknowledge.fao.org/handle/20.500.14283/cb6742en) | The lab follows AESA’s observation, data collection, analysis, and decision-discussion structure without converting an observation into an automatic prescription. |
| [FAO, *Global Farmer Field School Platform: Overview*](https://www.fao.org/farmer-field-schools/overview/en/) | The field is treated as a setting to test and integrate local knowledge and scientific insight through direct observation, comparison, reflection, and context-specific decision-making. |
| [Michigan State University Extension, *Integrated Pest Management Scouting in Field Crops*](https://www.canr.msu.edu/resources/pest_scouting_in_field_crops_e3294) | The lab uses a repeatable, broad field-walking route and records field location, crop condition, and unusual patterns before moving to a closer investigation. |

These sources support an evidence-first educational workflow. They do not authorise the platform to identify a disease, prescribe a product, set a treatment threshold, or replace current local guidance, labels, laboratory evidence, extension support, or specialist referral.
