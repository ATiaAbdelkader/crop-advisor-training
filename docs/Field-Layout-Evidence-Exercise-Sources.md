# Field Layout Evidence Exercise: Design Sources

| Source | Design implication |
|---|---|
| [FAO, *Grow: Planting*](https://www.fao.org/4/i1118e/i1118e07.htm) | Learners should plan field preparation and mulch responsibilities before implementation rather than treat practices as generic instructions. |
| [University of New Hampshire Extension, *Preparing a Vegetable Garden Site*](https://extension.unh.edu/resource/preparing-vegetable-garden-site) | Field preparation begins with site assessment and soil testing; crop-specific layout and support decisions need current local verification. |

The Module 21 exercise will support layout observation, readiness checks, and escalation. It will not prescribe mulch materials, support structures, rates, dimensions, or field operations.
