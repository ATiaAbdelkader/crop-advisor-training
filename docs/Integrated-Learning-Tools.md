# Integrated Field-Learning Tools

**Status:** Implemented learner-development layer.  
**Author:** Manus AI  
**Purpose:** Extend field transfer, access, and developmental feedback without altering the programme’s formal progression model.

## Learner workspace

The **Practice** workspace brings seven support surfaces into one learner-facing page. Learners can use private recent activity to select a practice route, work richer evidence-led cases, print or save concise field cards, switch between English/French/Arabic field cues, use larger reading text or device speech, and prepare a voluntary capstone case conference. Course administrators additionally see calibration prompts that support comparable evidence review.

| Support surface | Practical learner use | Formal-progression boundary |
|---|---|---|
| Adaptive practice | Use a missed formal check or scenario as a cue to recall, compare, and rehearse evidence. | Guides practice only; does not change a score or unlock sequence. |
| Branching field cases | Rehearse soil-protection and nursery-readiness decisions alongside earlier applied scenarios. | Keeps decisions evidence-led and non-prescriptive. |
| Offline field-card pack | Print or save concise prompts for observation, root-zone checks, water, nutrients, nursery, and scouting. | A field aid, not a substitute for current local advice. |
| Plain-language cues | Use the core decision cycle in English, French, or Arabic; review translated captions for Modules 11–20. | Translation support does not change course evidence standards. |
| Accessibility tools | Increase reading size, use low-data text mode, or listen through a device speech voice. | Device-dependent support; no learner data is sent to a speech service. |
| Calibration prompts | Help administrators compare evidence, recognise access factors, and keep feedback within safe boundaries. | Does not replace the existing supervisor scoring criteria. |
| Capstone case conference | Prepare a field-evidence, decision, enterprise, and recheck/referral explanation before a discussion. | Voluntary preparation; it is not a certificate or module gate. |

## Decision and safety boundary

> The tools are intentionally developmental. They do not change formal assessment scores, the **80% pass rule**, sequential gates, competency scoring, certification, or owner alerts.

All high-consequence crop-protection and agricultural advice remains bounded. The tools do not create product selections, rates, universal thresholds, medical response, cleanup or disposal instructions, legal reporting, or unverified local requirements. Learners should use current labels, authorised channels, laboratory evidence, extension, or specialist referral as appropriate.

## Validation

The implementation adds two source-aligned branching cases for soil-protection runoff risk and nursery batch readiness, as well as regression coverage for the 16-case scenario bank, printable-card resources, multilingual cue data, caption coverage, calibration prompts, capstone conference flow, and the non-gating boundary.
