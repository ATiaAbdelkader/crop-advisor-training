# Module 2: Root-Zone Evidence Source Notes

This short internal note records the external material used to strengthen the Module 2 learning sequence. It supports evidence-first instruction and does not establish regional nutrient, irrigation, or input prescriptions.

| Source | Design-relevant principle used in Module 2 | URL |
| --- | --- | --- |
| USDA Natural Resources Conservation Service, *Soil Health* | Soil performs interconnected water-regulation, nutrient-cycling, and root-support functions; root-zone observations should be interpreted as a system. | https://www.nrcs.usda.gov/conservation-basics/soil/soil-health |
| Ohio State University Extension, *Soil Sampling to Develop Nutrient Recommendations* | Representative sampling begins by separating decision areas using field history, crop response, drainage, and topography; laboratory results require sample context and calibrated interpretation. | https://ohioline.osu.edu/factsheet/AGF-513 |
| NC State Extension, *Soil, Water and Crop Characteristics Important to Irrigation Scheduling* | The root zone contains a changing water–air–solid balance, and effective rooting depth depends on crop and soil conditions. | https://content.ces.ncsu.edu/soil-water-and-crop-characteristics-important-to-irrigation-scheduling |

The implemented learning sequence therefore asks learners to compare matched areas, distinguish observations from inferences, preserve field context through sampling and interpretation, and use current authorised local guidance where an input decision is consequential.
